# Wave 1 — Spotlight blog: revert preset

**Topic:** Hold the event look. Revert when it ends.
**Persona:** Property A/V and ops who need rooms to return after events and timed looks without a manual rebuild.
**Source:** The Signal, Issue 02 (July 2026), “Set a revert preset.” Recast as a LUCI feature spotlight, not a customer how-to. Jane reframe (Sep 2026): lead with event-end return and timed holds; try-a-look is secondary. Mechanics: activate preset → auto-snapshot of before state; hold time optional for timed revert.
**CTA:** Soft demo — seeing it [in a short demo](/contact).

**Cover:**
- The problem (Jane open): change A/V for an event, then scramble to remember the prior state when it ends—or guess.
- The feature: snapshot of previous state + optional hold time + revert = the revert preset. Snapshot happens automatically on preset activation; without a hold time, no timed revert runs.
- The benefit: the room returns after the allotted time without rebuilding system by system.
- What they can do: event-end / timed holds (e.g. a two-minute promo), and (secondary) try a look with a way back.
- Optional teaser that shows the move (never “easy”): activate, set a hold, revert.
- Close on the demo, not a training manual.
