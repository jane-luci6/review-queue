# Wave 1 — Spotlight blog: morning reset

**Topic:** Start the day on a known look.
**Persona:** Property A/V and ops who have never run LUCI. They live with “who changed the floor last night.”
**Source:** The Signal, Issue 01 (June 2026), “Set a morning reset.” Recast as a current-LUCI feature spotlight, not a customer how-to.
**CTA:** Book a walkthrough. See a morning reset in LUCI.

**Cover (do not write a procedure):**
- The problem: every morning the floor is a negotiation — leftover looks, leftover volumes, leftover sources.
- The feature: a morning reset in current LUCI. One command, the house returns to a known state.
- The benefit: the day starts on purpose, not on whatever last night left behind.
- What they can do: set the look the property actually wants at open, then get it back without rebuilding it.
- Optional teaser that shows the move (never the word “easy”): choose the preset, apply it, the floor matches.
- Close on one interface for the A/V, and the walkthrough.

Constraints for every piece

- Always write A/V.
- LUCI works with and absorbs the systems already on the floor. It does not replace them. Do not name partners. Never call LUCI a layer.
- New LUCI is beta, property by property. Not a public splash. Do not write “we launched.”
- Do not invent ROI, percentages, or extra stats. Only facts in this brief.
- Never write the word “easy.” If a teaser shows the move, show the move.
- Named properties only if this brief names them. Do not add others.
- Institutional voice. Short. LUCI is the means, not the hero speech.
