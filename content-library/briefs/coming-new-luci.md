# Wave 2 — Blog: what is next in LUCI (not a splash)

**Topic:** More control where the work happens — without a launch announcement.
**Persona:** Prospects who already understand current LUCI and want the truth about what is next.
**Source:** The Signal, Issue 03, “What’s coming in the new LUCI.” **Not a ship post. New LUCI is beta. Not “we launched.”**
**CTA:** Book a walkthrough of current LUCI. Ask about beta only if they are a fit — do not pitch beta as a public product.

**Cover:**
- Current LUCI is the story on this site. The next version is not a splash page.
- If you name a next capability, keep it benefit-first (control in the venue, prepare a look before it is live, a record of what happened). Do not dump the feature list.
- Strip Issue 03 launch framing, sneak-peek language, and “first time outside the company.”
- Always A/V. Works with existing systems. No layer. No replace.
- If it starts to sound like a What’s New one-pager for existing customers, stop. That asset is not this blog.

Constraints for every piece
- Readers are new prospects (property A/V, IT, ops leadership). Not a customer operating manual.
- Always write A/V.
- LUCI works with and absorbs the systems already on the floor. It does not replace them. Do not name partners. Never call LUCI a layer.
- New LUCI is beta, property by property. Not a public splash. Do not write “we launched.”
- Do not invent ROI, percentages, or extra stats. Only facts in this brief.
- Never write the word “easy.” If a teaser shows the move, show the move.
- Named properties only if this brief names them. Do not add others.
- Institutional voice. Short. LUCI is the means, not the hero speech.
