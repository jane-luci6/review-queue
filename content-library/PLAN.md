# Website content library — plan

Prospect site. Not a customer operating manual. Signal stays the letter.

CoS owns this from brief to live. Jane writes copy in Cursor with ChatGPT from the briefs. Design locks look per type. Maker builds on luci-website. Review before Jane.

## Locked list

**Out:** EverPass / Sunday Ticket (back to DirecTV). Operator how-tos, checklists, booth sheets, playbooks. A second Guide. Invented stats. Partner names. “LUCI replaces.” The word “easy.”

### Wave 2
- Mike lighting-as-design blog (new use; can open the lighting spotlight).
- Mike partnership blog (new use; pull-quotes on case-study posts).
- “What’s coming” blogs (summer, August / Command Trail, new LUCI), recast so passed dates aren’t promised. New LUCI stays beta. Optional infographic if one picture is honest.
- Three issue intros as monthly reflections, expandable.
- Prospect checklists (not LUCI operating cards): current-state control/view audit; day-to-day A/V checklists that help without LUCI; current-state vs LUCI on one interface (no named competitors, no “replaces”).

### Wave 3
- Aliante page honesty, then Aliante case-study blog.
- Consolidation proof: infographic, blog, video.
- First quarterly “Where LUCI has been” video.

## Pipeline (every piece)

2. Jane ChatGPT in Cursor

4. Built on luci-website
5. Review
6. Jane
7. Live
