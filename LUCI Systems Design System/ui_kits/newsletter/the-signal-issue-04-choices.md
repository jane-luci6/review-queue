#### Design divisible rooms as operating modes

**Ready** — Plan removable-wall event spaces so audio and video zones can combine or separate with the room instead of becoming a manual exception.

**Ready** — Give each cabana, conference room, or pool area the few controls it needs while the wider environment stays coordinated.

#### Protect the live room from the next change

**Ready** — Separate preparation from execution so an operator can build what comes next without disturbing what guests see now.
