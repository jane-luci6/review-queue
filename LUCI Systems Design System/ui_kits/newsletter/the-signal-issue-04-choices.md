## Advice — still open

**Divisible rooms are operating modes** — Ready
When the wall comes out, audio and video combine with the room. When it goes back, they split. You don’t lose that.

**Keep local control local** — Ready
The cabana or conference room gets the few controls it needs. The rest of the house stays coordinated. An operating rule, not a product.

**The systems already in the room stay** — Ready
LUCI coordinates them. It does not replace the A/V already bought.

**Expansion should join the house, not start a second console** — Ready
A new wall or room comes onto the interface already running the property.

**Use the plant that’s already in the floor** — Ready
If the old run still works, send the new stream back out on it. Don’t trench the floor to prove a point.

**Watch the calendar collision** — Ready
If two presets share the same TVs, the next one wins. Don’t stack a drawing on a daypart without a plan.
