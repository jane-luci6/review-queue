Field Setup Guide

LG STB-6500 Pro:Centric Setup

Belterra Park · Internal · Rev 1 · October 2026

Configure each new STB-6500 set-top box on the bench, label it, and repack it in its own numbered box. Pro:Centric pairs the box to the LUCI server, downloads the profile, and reboots. Factory reset is only for boxes that don't set up correctly — see Troubleshooting on page 4.

Before you start Open the Install Log on the last page — every box gets one line, numbered from 155 up. Never reuse a number.

Settings at a Glance

Step 1

Assign an IP and label the box

Pick the next unused number, write it on the STB and the shipping box, and log it before you touch network settings.

  1. 1

    Pick the next unused IP. Start at 10.14.153.155, count up, and never reuse a number.

  2. 2

    Label the STB. Write the last octet on the box itself — e.g. 10.14.153.155 → 155.

  3. 3

    Mark the shipping box with the same number so the STB and its box stay paired.

  4. 4

    Log it. Fill in the matching line on the Install Log (last page) before moving on.

Step 2

Network Configuration — set a static IP

Open the network menu, switch off auto, and enter the static IP you picked in Step 1. The DNS warning at the end is expected.

  1. 5

    Open Network Configuration on the STB menu.

  2. 6

    Select Network Setting.

  3. 7

    Choose Wired Connected.

  4. 8

    Select Edit.

  5. 9

    Uncheck Set Automatically. The box switches to Static IP.

  6. 10

    IP Address — enter10.14.153.[label]

    Examplefor box 155, enter 10.14.153.155.

  7. 11

    Subnet Mask — enter255.255.252.0

  8. 12

    Gateway — enter10.14.152.1

  9. 13

    Select Connect.

    ExpectedA No DNS error is normal here — press Back. The static IP is kept.

Step 3

Pro:Centric Server — point the box at LUCI

Walk the Pro:Centric wizard to Manual / HTML, enter the LUCI server address and port, then let the box find the server and pull its profile.

  1. 14

    Press Next through the Pro:Centric intro.

  2. 15

    Press Next again.

  3. 16

    Select Pro:Centric Manual.

  4. 17

    Select HTML.

  5. 18

    Server IP — enter10.14.152.30

  6. 19

    Server Port — enter2126

  7. 20

    Select Search.

    ExpectServer Found. If not, see Troubleshooting on page 4.

  8. 21

    Press Next. The download starts.

    CautionDo not unplug the box while it downloads.

  9. 22

    Select Reboot. Let it finish restarting.

Step 4

Finish — confirm, repack, log

Verify the three numbers match, put the box back in its numbered carton, and check it off on the Install Log.

  1. 23

    Confirm the label. The STB, the shipping box, and the IP must all show the same number.

  2. 24

    Repack. Unplug the box and put it back in its numbered shipping box.

  3. 25

    Complete the log. Check off the row for this box on the Install Log (last page).

Troubleshooting

When a box won't set up

Server not found

  • Check the network cable and link light on the STB.
  • Re-check the IP, subnet, and gateway from Step 2.
  • Make sure the IP isn't already in use on the network.
  • Confirm the server IP is 10.14.152.30 and port is 2126.

No DNS error on Connect

  • Normal. Press Back — the static IP is kept. Continue to Step 3.

Wrong IP, download fails, or box won't finish

  • Run the Factory Reset below.
  • Restart at Step 2 using the same IP and label.

Factory Reset · InStop — only if setup failed

Use this only when a box won't take its profile. After the reset, return to Step 2 with the same IP and label.

  1. Open the Installer Menu: press Menu ten times, then 9 8 7 6, then Exit.
  2. Enter 117 then press Menu.
  3. Enter 413 then press OK.
  4. Enter the password 0413.

Code sequence: Menu ×10 → 9 8 7 6 → Exit → 117 + Menu → 413 + OK → 0413.
