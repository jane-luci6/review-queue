LG STB-6500 Setup

Configure each new STB-6500 set-top box on the bench, label it, and repack it in its own numbered box. Pro:Centric pairs the box to the LUCI server, downloads the profile, and reboots. Factory reset is only for boxes that don't set up correctly — see Troubleshooting on page 3.

Before you startOpen the Install Log on the last page — every box gets one line, numbered from 155 up. Never reuse a number.

Step 1

Assign an IP and label the box.

# Select / Do Enter You should see
01 Pick the next unused IP Start at 10.14.153.155 and count up. Never reuse a number.
02 Label the STB Write the last octet of its IP on the STB. Example: 10.14.153.155 → 155
03 Mark the shipping box Write the same number on the box this STB goes back into.
04 Log it Fill in the line for this box in the Install Log on the last page.

Troubleshooting

When a box won't set up.

Server not found

  • Check the network cable and link light.
  • Re-check IP, subnet mask, and gateway (Step 2).
  • Make sure the IP isn't already used by another box.
  • Confirm server IP 10.14.152.30 and port 2126.

No DNS error on Connect

  • Normal. Press Back — the static IP is kept.

Wrong IP entered, download fails, or box won't finish setup

  • Factory reset the box (below), then start again at Step 2 using the same IP and label.

Factory reset · InStopOnly run this when a box won't set up correctly. It erases the current configuration.

  1. Open the Installer Menu: press Menu ten times, then enter 9 8 7 6, then Exit.

  2. Enter 117, then press Menu.

  3. Enter 413, then press OK.

  4. Enter the password 0413.
