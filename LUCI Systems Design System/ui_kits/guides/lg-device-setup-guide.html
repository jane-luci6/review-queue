LG Device Setup

Run these three procedures on every LG TV and STB — static IP, LUCI server pairing, profile download and reboot, plus a factory default when you need to reprovision a device.

Before you startHave the Project Document open — it lists the approved static IP mapped to each TV and STB number.

Network Configuration

Set a static IP on the device.

  1. Open Network Configuration, then Network Setting.

  2. Select Wired Connection, then Edit.

  3. Deselect Set Automatically to switch the connection to Static.

  4. Enter this device's approved static IP address — the address mapped to its TV or STB number in the Project Document.

  5. Enter the Subnet and Gateway values listed below.

  6. Select Connect.

    Ifno DNS is present, an error message appears — select Back and the static IP will remain set.

  • Gateway[Gateway]
LUCI · [Property name] — LG Device Setup 01 / 03

Pro:Centric LUCI Server

Point the device at the LUCI server.

Configure Pro:Centric manually, enter the server address and port, then download the profile.

  1. Select Next, then Next again.

  2. Choose Pro:Centric Manual.

  3. Set the delivery type to HTML.

  4. Select IP and enter the LUCI server address [Server IP].

  5. Select Port and enter the server port [Port].

  6. Select Search. You should see Server Found.

  7. Select Next to start the download.

  8. Reboot the device once the download completes.

Server values · this property

  • LUCI server IP[Server IP]
  • Server port[Port]
LUCI · [Property name] — LG Device Setup 02 / 03

InStop · Factory Default

Reset a device to factory default.

If a device won't pair or the download fails, confirm its static IP against the Project Document and that it can reach the LUCI server — then factory default and start the setup again.

Caution: Factory default erases the device's current configuration. Only run it when you intend to reprovision the TV or STB from the start.

  1. Open the Installer Menu: press Menu ten times, then enter 9 8 7 6.

    Confirmpress Enter on a TV, or Exit on an STB.

  2. Enter 117, then select Menu.

  3. Enter 413, then select OK.

  4. Enter the password 0413.

Installer codes · reference

  • Installer menuMenu ×10 → 9 8 7 6
  • Menu code117
  • OK code413
  • Password0413

Repeat all three procedures on every TV and STB on the floor. Stuck on a device? Reach your LUCI deployment lead or post in the install channel with the device's TV/STB number.
