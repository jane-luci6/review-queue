Section subhead — format samples

Each FAG section has a kicker (Section 01), a big name (Marketing & Guest Experience), a mint rule, then a line that reads like a subhead but is currently styled as body copy. Below are four ways to format that subhead line. Same content in each; only the subhead treatment changes. Shown on dark — each adapts to the light sections (mint → --accent-light, off-white → --ink-strong).
