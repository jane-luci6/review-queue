How-to panel — redesign options

Four directions for the “How to do it” accordion panel, to fix the cluttered read and give it a clear text hierarchy.

All four use the same content (IT use case 01 — Add an endpoint) so you can compare the hierarchy directly. Panels are shown open. Pick A, B, C, or D and I’ll merge the winner into the guide.

Option A

Big numerals & zoned headers

Three labeled zones — Before you start / Step by step / This week — with oversized mint step numbers in a left gutter. Hierarchy comes from the big numerals and the zone labels with trailing rules.

Before you start

You have an admin PIN and the device’s IP address — it must match the field device (the set-top box/TV, the DSP, or the lighting system).

Step by step

  1. Log in to LUCI with your admin PIN.
  2. Left menu → Administration → Map Modes → Device Setup [Administration].
  3. Select the device type: Video, Audio, or Lighting [Devices]. (On LUCI v2.34.0+, use the Endpoint Manager instead.)
  4. Navigate the map to where the endpoint lives.
  5. Right-click (or long-press) the map → Add Endpoint (for lighting, Add Device).
  6. Video only: pick the Brand from the dropdown. (Audio and lighting skip this.)
  7. Name the endpoint — this is the label shown on the UI.
  8. Notes: add asset tagging or other info you want to track.
  9. Device Address: enter the IP that matches the field device (video: the set-top box/TV; audio: the DSP; lighting: the lighting system).
  10. Assign the endpoint to a Venue so every user on that venue can reach it (unless you restrict it per user — see IT UC03).
  11. Video only: toggle Auto Power to let a watchdog keep the device powered on.
  12. Set any other relevant options, then click Save.
  13. To edit later: right-click the device on the map (or in the Assigned list) → Edit Endpoint.
