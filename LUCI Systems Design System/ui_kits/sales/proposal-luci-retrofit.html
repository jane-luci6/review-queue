Scope of Work

Included in this proposal

  • LUCI OS platform licensing and configuration
  • Endpoint licensing — video and audio zones
  • Integration hardware (encoders, set-top boxes, control tablets)
  • System integration and programming by LUCI certified technicians
  • Project management from contract signing through final acceptance
  • On-site operator training and documentation
  • Predictive monitoring setup and alert configuration
  • 2-year comprehensive SLA warranty

Not included

  • Structural modifications or building permits
  • Electrical service upgrades
  • Content creation or media licensing
  • Data cabling and network infrastructure beyond the rack
  • Extended warranty beyond the included term

All work is performed by LUCI Systems certified technicians. Installation timeline and milestones are established during the project kickoff meeting. LUCI works closely with the property team to ensure accurate placement and configuration of all endpoints. The platform integrates with existing A/V, signage, and building systems via open APIs.

Upon installation completion, LUCI Systems conducts a formal walkthrough with the client. Any deficiencies are documented and resolved within the agreed timeline. Final acceptance triggers the warranty start date.
