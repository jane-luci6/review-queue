Marketing & Guest Experience

Every screen on the property is now yours to program by zone, by daypart, in real time.

The reach that used to live on a handful of dedicated signs now covers the whole floor.

  • 01

    Push a message to every screen in under two minutes.

    With LUCI, you make the edit on your own device, send it to the whole floor or a single set of zones, and it’s live in moments — then drop back to the scheduled plan when you’re done.

    • React while the moment still matters, instead of after it passes
    • No ticket, no call, no waiting on another team’s queue
    • Every screen stays current — none stranded on yesterday’s message

    How to do it →

    One-time setup — get the message into LUCI as a channel

    1. In Telemetry TV, open Media and drag your message asset in (or pull it from a linked OneDrive/Canva). Set a validity end-date if it’s temporary so it auto-removes.
    2. Create a Playlist, add the message to it, and assign the playlist to a Telemetry player. That player’s output feeds a LUCI IP encoder, so the message now appears as a channel in LUCI’s source list.
    1. Open LUCI in your browser from any device and log in.
    2. On the property map, zoom out until every display on the floor is in view.
    3. Use the lasso tool to select every TV on the property — or select just the zones you want to reach.
    4. In the source list, pick the channel carrying your message. Every selected display flips to it immediately, live, with no ticket or call.
    5. To drop back: set a revert time (e.g., 60 seconds) and the floor returns to its scheduled content on its own — or apply your “normal” preset when you’re done.

    This week →Find one piece of content that needed outside help to change last time. Push it yourself today.

  • 02

    Daypart your restaurant promotions to catch guests at the decision point.

    Schedule a dining spot to run across the floor in the hour before lunch and again before dinner — the windows when guests are deciding whether to stay on property or head out — then reset the regular rotation automatically. Set the timing once and it repeats every day.

    • Capture covers that would otherwise walk out the door
    • Reach guests anywhere on the floor, not just the screens by the restaurants
    • Lift on-property spend in the same move

    How to do it →

    One-time setup — same as use case 01

    1. Load the dining spot in Telemetry TV, put it on a playlist, and assign to a player so it appears as a channel in LUCI.
    1. In LUCI, open Presets and create a new preset (e.g., “Pre-lunch dining spot”).
    2. Add the displays you want to reach — the floor-wide set, not just the screens near the restaurants. Select them on the map or from the venue list.
    3. For each display in the preset, set its target to the dining spot channel.
    4. Save the preset.
    5. Open the Event Scheduler. Add the preset to the calendar at 11:00am (and a second entry at 5:00pm for dinner). Set it to repeat daily, or pick specific days.
    6. Set a revert time on each entry (e.g., 60 minutes) so the floor drops back to regular rotation automatically — or schedule a “normal” preset to follow it.

    This week →Build a pre-lunch dining spot. Then stand on the floor at 11am and watch it run.

  • 03

    Run customized content by zone — indoor and outdoor — from one control panel.

    The sports book, the main floor, the bar, and the marquee can each run their own schedule at the same time, every display managed from the same place — including external signage connected through LUCI. Program each space for what it needs in the moment instead of broadcasting one message everywhere.

    • Speak to each audience in the zone where they actually are
    • Bring the marquee and outdoor signs into the same plan as the floor
    • Promote in one zone without disturbing play in another

    How to do it →

    One-time setup — one channel per zone’s content

    1. In Telemetry TV, load each zone’s content as a separate playlist on a separate player (one player per simultaneously-running piece of content). Each player feeds a LUCI encoder and becomes its own channel in LUCI.
    2. For outdoor signage: confirm with your A/V team which external displays (marquee, outdoor signs) are wired into LUCI encoders. If they are, they show up as displays on the map and are managed exactly like indoor screens.
    1. In LUCI, open the property map and pick the first zone (e.g., sports book). Select it from the venue list or tap its tag.
    2. Select the displays in that zone, then in the source list pick that zone’s content channel. They flip immediately.
    3. Repeat for each zone — main floor, bar, lobby, marquee — each running its own content at the same time.
    4. To make it repeat: build one preset per zone (that zone’s displays + that zone’s channel) and schedule each on its own calendar. Zone schedules are independent, so the sports book can run on one cadence while the bar runs on another.
    5. Walk the floor to confirm each zone is playing what you intended, and adjust the channel or schedule from the same panel.

    This week →Pick a day, choose two or three zones, and run zone-specific content. Walk the floor to see how they play out.

  • 04

    Build an event campaign that escalates automatically.

    Schedule a rotation that grows an event’s presence — more zones, more frequency — as the date approaches, and fills your slow dayparts with loyalty and dining offers in between. Build it once; it ramps and resets on its own.

    • Build momentum toward an event without touching it daily
    • Put historically slow windows to work instead of waiting them out
    • Return the floor to normal automatically, with no stale content left running

    How to do it →

    One-time setup — content + frequency

    1. In Telemetry TV, load the event promo asset(s). For higher frequency closer to the event, build a playlist that rotates the promo more often — frequency is controlled on the CMS side, zone coverage on the LUCI side.
    1. In LUCI, build a series of presets, each wider than the last: Preset A = one zone (e.g., lobby) on the event channel; Preset B = lobby + concourse; Preset C = full floor on the event channel.
    2. Open the Event Scheduler and place Preset A on the calendar for two weeks out, Preset B for one week out, and Preset C for the week of the event. Each can repeat daily during its window.
    3. To fill slow dayparts between campaign windows, schedule a separate preset that pushes loyalty and dining offers during historically slow windows.
    4. Schedule a “return to baseline” preset for the day after the event (or set revert times on Preset C) so no stale event content keeps running.
    5. Build it once — the calendar ramps and resets on its own from there.
