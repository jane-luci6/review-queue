Templates for Cursor

Copy a template URL and paste it into Cursor chat. Cursor fetches the skills and constraints for that document — no folder setup required.

URL workflow
  1. Click Copy URL below — paste into Cursor chat with client notes
  2. Click-to-edit: open the same URL in a browser (or Cursor Simple Browser). Click highlighted text and type.
  3. Use Copy updated HTML on the edit bar when finished
    Cursor reads these files automatically (via project rule + starter prompt):
    • CURSOR.md — URL routing (this folder)
    • <template>/SKILL.md — editable vs locked pages
    • _brand/SKILL.md — typography, color, voice
