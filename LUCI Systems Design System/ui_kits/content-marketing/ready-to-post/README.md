# Ready to post

Finished social content only. Nothing in here needs more work — grab it and post it.

Work in progress lives in the **LUCI Social Bench** artifact. This folder and the
**Ready to Post** artifact are the finished end of that pipeline.

## How it's organised

One numbered folder per post, in posting order:

```
001-orchestration-engine/     What runs your property? (carousel)
002-pin-zone-access/          Who's allowed to touch that screen? (single image)
```

Each folder has:

- **POST.md** — the caption to copy, upload instructions, and anything to check
  before posting
- **the asset(s)** — the PDF to upload for carousels, or the PNG for image posts
- individual slide PNGs where relevant, as backups for reuse in decks

## Numbering

The number is the intended posting order, not the date. `001` is the first LUCI
post. Keep numbering sequential as posts are added so the queue and the folders
stay in sync.

## Marking things posted

Use the **Ready to Post** artifact — it has a mark-as-posted toggle per post and
keeps the published date. This folder doesn't track state; it's just the files.
