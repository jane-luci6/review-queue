Friday prep

Every Friday, prep the next week’s 2–3 posts. Say Friday social prep or prep next week’s posts in chat to start.

  1. Drop media into social-intake/<posting-week-Monday>/raw/ (or attach in chat). No new photos? Say so — Cursor searches existing content.

  2. Review treatments. Cursor proposes cuts, crops, before/after pairs, silent reels, stills-from-video, and does the edits into exports/.

  3. Lock the 3-slot batch: Tue = weekly series · Wed = field / case · Thu = thought leadership, snippet, or news.

  4. Fill the templates below, run each checklist + the close check, then assemble into social-this-week.html for Preview Hub review. IMP only when you say the batch is ready for Mike.

Weekly series still pending. Five Season 1 formats (each with an 8–10 week topic bench) live in Weekly series — Season 1 proposals. Until one is locked, Friday prep will propose options for Tuesday and ask you to pick before drafting series copy.

How to use this space

Each template below is a fill-in card with the fields, the checklist, and the sign-off sensitivity for that post type. The discipline is the same every week: pick the type, fill the fields, run the checklist, run the close check, then copy the finalized post into social-this-week.html. The templates are reference — they don’t auto-save anywhere. The single source of truth for a given week is social-this-week.html.

The hook-and-close rule, on every post. The visual is the hook (wall, rack, crew, before/after, diagram). The caption always closes on the abstraction — one interface, one team, one accountable system. If a draft stops at the gear, it isn’t done.

The close check (run on every draft before the batch)

Before a draft leaves this studio for social-this-week.html, it passes these five. If any fails, fix or cut — don’t send Mike a draft that hasn’t passed.

  • Pillar tag. The post clearly serves one of the four pillars. No pillar, no post.

  • Hook-and-close. The visual is the hook; the caption closes on the abstraction (one interface / one team / one accountable system), not on the gear.

  • Audience fit. The caption answers “what does this mean for the person running the property?” — not “what gear is in the frame?”

  • Voice flags. A/V (not AV), no “layer” for LUCI, describe what the platform does not how it feels, no repetition of “engine” / “orchestrates” in a short caption.

  • Anonymization & proof rules. Field posts have no client identifiers; named case-study / video posts have client OK on file; no % boasts or unverified metrics.

Then: copy the finalized post into social-this-week.html, rebuild the review portal, and the page is already linked from the Review Queue for Mike’s weekly batch sign-off. See the strategy · sign-off workflow for the full six-step flow.
