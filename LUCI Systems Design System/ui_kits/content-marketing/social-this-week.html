Rebuilding this page each week

This is a template as much as a page. Each week: Jane drafts in the Social Studio, finalizes the week’s 2–3 posts into this file (replacing the previous week’s content), bumps the week-of date, and rebuilds the review portal. The page stays linked from the existing Review Queue — no new queue section, just a link.

  • Week of: update the masthead date and the “The ask” week strip.

  • Posts: one .stw-post card per finalized post, tagged with type and pillar. Cut a card if a post is dropped.

  • Checklist: each card carries its type’s sign-off checklist so Mike can see what was already screened.

  • Rebuild & deploy: node scripts/build-stakeholder-review.mjs → npm run deploy:portal. The page is already wired into review-queue.json.
