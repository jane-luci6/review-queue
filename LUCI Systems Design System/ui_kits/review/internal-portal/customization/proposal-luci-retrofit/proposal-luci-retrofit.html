Project overview

Project Intent

LUCI will upgrade and re-unify the Ameristar Black Hawk A/V system by consolidating multimedia distribution, routing, control, and support into a single LUCI-managed platform. This work replaces the aging Crestron control environment, BSS audio processing, and the existing AV Ethernet network architecture with a modernized design focused on reliability, serviceability, and reuse of existing infrastructure wherever feasible.

Key outcomes

  • Unified multimedia operations (property-wide oversight, maintenance, support, and control)
  • Modernized IPTV distribution using a COM3000 platform with 92 DirecTV channels
  • Expanded local content ingestion via LUCI encoders (digital signage/marketing, gaming feeds, music videos, and other local sources)
  • Network overhaul with a data-center hub, 10Gb backbone to IDFs, and secure remote access architecture
  • Maximized reuse of existing speakers, cabling, racks, power, and endpoint devices wherever viable
02

Project overview

Guiding Principles

  • Reuse-first: preserve and validate existing infrastructure (speakers, cabling, racks, power, mounts, displays) unless it directly prevents a reliable solution.
  • Operational consistency: unified workflows and standardized control experiences across venues/spaces.
  • Serviceability: remote monitoring, remote support access, simplified troubleshooting, and reduction of single points of failure.
  • Phased execution: deliver functional value early; defer optional/secondary scopes where appropriate.

Project overview

Project Phasing

This phasing is a planning structure for scope responsibilities and sequencing; it was refined after additional tracing/validation of infrastructure terminations and stakeholder expectations during the onsite walk.

  • Phase 1 — Core platform + headends + IPTV foundation

    Deliver the core LUCI platform, core network backbone, IPTV COM3000 upgrade, and primary headend upgrades that establish the unified property foundation.

  • Phase 2 — Meeting/conferencing unification + room modernization

    Unify conferencing capabilities across meeting/hospitality rooms; centralize AV components into the appropriate IDF(s); replace projector/screen where required; address room combining workflows. This phase may be deferred based on stakeholder priorities, budget timing, and scope responsibility alignment.

  • Phase 3 — Optional consolidation / specialty expansions

    Sportsbook consolidation (if deferred), additional venue enhancements, incremental content ingestion expansions, and any identified system additions identified during scope review.

Technical scope

System Scope

4.1 LUCI platform (multimedia unification)

LUCI will provide an integrated platform to manage:

  • IPTV channel distribution and selected local source routing
  • Control surfaces/workflows for authorized users (role-based access where applicable)
  • Scheduling/automation for common operational states (as defined in stakeholder workshops)
  • Monitoring/support pathways for remote diagnostics and operations
LUCI Systems · Proposal 05

4.2 IPTV upgrade (COM3000 + DirecTV)

LUCI will upgrade the IPTV distribution system to the COM3000 platform including:

  • 92-channel DirecTV lineup (exact channel map confirmed with Ameristar stakeholders)
  • Network distribution to all designated TVs on property, including back-of-house displays
  • Integration with LUCI for unified routing/operational control (as applicable)

4.3 Local content ingestion (LUCI encoders)

Expand and/or upgrade LUCI encoders to ingest and distribute local content sources such as:

  • Digital signage marketing content/messages
  • Gaming feeds
  • Music video channels
  • Other approved local sources (finalized during scope review)

Deliverables include

  • Source list + ingest method per source (HDMI/SDI/IP/etc. as applicable)
  • Routing rules and operational presets in LUCI for each venue/zone as required

4.4 Audio system modernization (Q-SYS)

Replace the legacy BSS audio processing with Q-SYS, including:

  • Redundant DSP architecture where required for the main casino head-end
  • Modern amplification aligned to zone layout and existing loudspeaker infrastructure
  • Centralized audio routing and zone control via LUCI workflows
LUCI Systems · Proposal 06

4.5 Network overhaul (AV network + backbone)

Implement a modernized AV network design with the Data Center as the hub, including:

  • 10Gb backbone uplinks from the data center to supporting IDFs serving AV systems
  • Replacement/upgrade of network switches required to support IPTV, encoders, DSP, control, and management traffic
  • Segmentation and routing rules to protect guest traffic and maintain AV reliability

4.6 Secure remote access architecture (LUCI-provided firewall)

Provide a LUCI-supplied firewall enabling secure remote access for authorized users and support. Architecture intent (refined during scope review):

  • A user on Ameristar Black Hawk Guest Wi‑Fi uses an approved control surface device.
  • The device routes out to the internet and back in through a segregated ISP path terminating at the LUCI-provided firewall.
  • The firewall provides authenticated, policy-controlled access to the segmented AV environment without bridging Guest Wi‑Fi directly into the AV network.

Architecture deliverable

  • A short architecture diagram + written explanation identifying the VLANs/ISPs, authentication method, and permitted flows for control and support.
