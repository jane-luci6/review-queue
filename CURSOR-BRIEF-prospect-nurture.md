# Brief: Prospect Pulse: shared six-month nurture (PULSE-01..06)

FIRST read `CURSOR-BRIEF-prospect-shared.md` (repo root, same folder as this brief) and obey it completely. This brief scopes one chunk.

Write ONLY these emails (scaffold paths are relative to `LUCI Systems Design System/ui_kits/internal-portal/email-copy/`). Output JSON file: `PROSPECT-nurture.json` in that same `email-copy/` folder.

### Cycle: Every 4–6 weeks
- **PULSE-01** (`PULSE/PULSE-01-orchestration.md`) #1 Orchestration from one interface
  - Timing: Month 1
  - Purpose: Start with the operational drag of separate interfaces, vendors, and workflows. Tie the problem to LUCI's property-wide orchestration and control, with the recent New LUCI release as supporting proof that this control continues to expand.
  - CTA: See how LUCI runs the property from one interface.
- **PULSE-02** (`PULSE/PULSE-02-consolidation-over-replacement.md`) #2 Consolidation over replacement
  - Timing: Month 2
  - Purpose: Frame the choice between another replacement cycle and a standardized platform that consolidates the environment. End with the strongest invitation to revisit LUCI.
  - CTA: Compare the next refresh with a LUCI operating model.
- **PULSE-03** (`PULSE/PULSE-03-one-shared-operating-view.md`) #3 One shared operating view
  - Timing: Month 3
  - Purpose: Show the cost of operations, IT, marketing, and leadership working from different systems or assumptions. Tie complete visibility — every endpoint from a map-based interface — to faster, more aligned decisions.
  - CTA: See how LUCI gives every team the same picture.
- **PULSE-04** (`PULSE/PULSE-04-aligning-teams.md`) #4 Aligning teams
  - Timing: Month 4
  - Purpose: Tell the story of an incident or decision crossing teams with no single owner. Tie in-product context, audit history, and the embedded team to one accountable response. Accountability is part of the alignment story, not a separate capability.
  - CTA: See how LUCI aligns the operation by default.
- **PULSE-05** (`PULSE/PULSE-05-activate-the-guest-experience.md`) #5 Activate the guest experience
  - Timing: Month 5
  - Purpose: Show the gap between passive screens and purposeful, real-time guest moments. Tie LUCI's ability to activate every endpoint to a tangible guest-experience outcome the prospect recognizes.
  - CTA: See how LUCI turns passive screens into guest moments.
- **PULSE-06** (`PULSE/PULSE-06-platform-that-scales-and-improves.md`) #6 A platform that scales and improves
  - Timing: Month 6
  - Purpose: Frame LUCI as the only A/V platform refined continuously and built to extend when the property expands. Use New LUCI as proof that the investment becomes more capable over time, not another replacement cycle.
  - CTA: See how the platform scales and improves.
