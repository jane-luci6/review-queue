The challenge: let the property grow without multiplying the operation

A casino floor, a ballroom, a restaurant venue, and a live-entertainment space ask different things of A/V. If each project arrives with its own operating logic, the property inherits more interfaces and more disconnected workflows every time it expands.

Ponca City’s history offers a different frame. LUCI was already running before the later projects began. The question at each new phase was not how to start over, but how to bring another space into the control environment the property already had.
